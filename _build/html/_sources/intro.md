### Overview

In recent years, Environmental Science has rapidly changed to a big data problem with remote sensing and model dataset rapidly increasing in size. Earth Observation (EO) satellites now produce over 100TB of data every day. This series is intended to introduce Python as a tool for interrogating large Earth Observation and geospatial datasets. Utilising a range of open-source packages, cloud computing, and application of machine learning technques, it is possible to process and analyse massive amounts of from your laptop. Here we provide some tools which can kick start your journey of geospatial big data exploration.

This website hosts 3 books (or courses) which build on each other but can also be treated as stand-alone resources. 
- **Book 1 - Python Software Carpentry** assumes no prior knowledge and introduces the some important underlying concepts that need to be understood before using Python as a scientific programming language. 
- **Book 2 - Geospatial and EO Data Analysis in Python** builds on Book 1, introducing a selection of the tools available to work with geospatial data in Python, with examples focused on Earth Observation and satellite datasets. 
- **Book 3 - Machine Learning for Earth Observation (EO)** introduces the application of machine learning techniques to EO data, addressing some of the technical challenges that to overcome compared to work with georeferenced and noisy satellite imagery, and demonstrating how machine learning can be a powerful tool for automatically processing and analysing very large EO datasets.


```{admonition} Learning goals
:class: tip

- Confident coding in Python, and aware of best practices if not regularly implementing the.
- Able to use Python to read, process, analyse, and visualise data in a variety of formats including tabular, vector, and raster.
- Filter and extract pertinent data from massive online data platforms using powerful tools such as xarray and Google Earth Engine.
- Develop and apply machine learning workflows, from data preparation through to training and evaluation. 
```

Python is the most popular programming language. This includes within Environmental Science and Machine Learning. And this is not without good reason: [Why Python keeps growing, explained.](https://github.blog/developer-skills/programming-languages-and-frameworks/why-python-keeps-growing-explained/) Therefore in these tutorials we focus on using Python for geospatial applications with a particular focus on the use of satellite data within Environmental Science. As is such with an open-source ecosystem, there are numerous ways of doing the same task, we show some good options but by no means are they the only way and keep you ears pricked because new libraries and updates are constantly being released! It is also worth mentioning that there are other tools beside python (e.g. QGIS, R), and python might not have the solution for every application. Often the answer lies in combining multiple tools, so keep an open mind, don't become to set in your ways, be open to learning new ways of doing things and adapting your workflow.
